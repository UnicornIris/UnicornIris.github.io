# Leyan Lyu Portfolio

A simple bilingual resume-style personal website for GitHub Pages, tailored for `SDE`, `MLE`, and `AI Product` applications.

## Files

- `index.html`: main resume-style portfolio page
- `styles.css`: simple responsive layout
- `script.js`: English / Chinese language switch plus click-to-expand experience panels
- `assets/profile.jpg`: portrait
- `assets/resume-en.pdf`: English resume
- `assets/resume-zh.pdf`: Chinese resume
- `assets/research-student.png`: research student poster
- `assets/research-intern.png`: research intern poster

## Publish on GitHub Pages

1. Create a GitHub repository, for example `leyanlyu.github.io`.
2. Upload the files in this folder to the repository root.
3. In GitHub, open `Settings` -> `Pages`.
4. Under `Build and deployment`, choose `Deploy from a branch`.
5. Select the `main` branch and the `/ (root)` folder.
6. Save, then wait for GitHub Pages to publish the site.

## Easy content updates

- Update the click-to-expand experience content in [index.html](/Users/luns/Documents/Codex/2026-04-25-files-mentioned-by-the-user-pdf/index.html).
- Replace placeholder blocks for non-research experiences with your own screenshots or photos.
- Swap in newer resumes by overwriting the PDF files in `assets/`.
